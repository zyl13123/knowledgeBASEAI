# 2026-08-07 工作日志

## Bug 修复：文档处理空段落导致 Gemini API 400 错误

- **根因**：`chunk-service.ts` 的 `chunkText()` 用 `text.split(/\n\n+/)` 切段落后，没有过滤空字符串。空段落传给 Gemini embedding API 时报 `EmbedContentRequest.content contains an empty Part`（400 Bad Request）
- **修复 1**：`chunk-service.ts` — 循环开头加 `if(!para.trim()) continue` 跳过空段落
- **修复 2**：`document-service.ts` — 切片后检查 `chunks.length === 0`，空文档直接标 `failed` 并 return，不调 API
- **修复 3**：`UploadZone.tsx` — 加 try/catch + res.ok 检查，上传失败时 alert 提示用户
- **经验**：Gemini API 对空内容的处理不稳定，同一个文件有空段落时可能有时过有时不过，不能依赖 API 容错
- **验证结果（03:14）**：修复后用户重新上传同一份"AI知识库问答系统-需求文档.md"，**成功**，问题确认解决。之前"同样文档一次成功一次失败"是因为 Gemini API 对空 Part 校验不稳定
