### 踩坑记录（重要）
- **instrumentation 文件名**：必须叫 instrumentation.ts（不带 s），带 s 的 instrumentations.ts 不会被 Next.js 识别，register() 不执行
- **embedding 模型**：text-embedding-004 已废弃 → gemini-embedding-001（免费层可用），且必须传 outputDimensionality: 768 匹配数据库维度
- **embedContent 传对象时**：content 必须是 { parts: [{ text }], role: 'user' } 结构，不能传裸字符串
- **CHAT_MODEL 建议升级**：gemini-1.5-flash 已过时，gemini-3.6-flash / gemini-2.5-flash 免费层可用
- **pdf-parse v2 API 变更**：v2.4.5 不再是默认导出函数，改为命名导出 PDFParse 类。import 要用 `import { PDFParse } from 'pdf-parse'`，用法是 `new PDFParse({ data: buffer })` → `await parser.getText()` → `await parser.destroy()`
